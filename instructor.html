LogiCola Instructor Report: check student score files (.lgc)

Drop student score files here, or

You can select a whole folder's worth at once. Nothing is uploaded anywhere; the files are read in your browser.

What a score file contains. The student's name, their best level for each set, and, for each activity and difficulty they finished: the best level, the first and last dates, how many times, whether answers were typed or picked from a list (MC), and the logic system used. LogiCola does not record answers or any other practice details. Files exported before this version show only "done" for a set; the activity and difficulty were not recorded then, so they are marked older format.

File check. verified means the file is exactly what LogiCola exported. altered means its signature does not match: it was edited after export, or damaged in transit, so ask the student to export it again. unsigned is an old file format whose levels cannot be verified.
