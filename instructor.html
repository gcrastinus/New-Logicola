LogiCola Instructor Report: check student score files (.lgc)

Drop student score files here, or

You can select a whole folder's worth at once. Nothing is uploaded anywhere; the files are read in your browser.

What a score file contains. Only the student's name, their best level for each set, and which sets they have finished. LogiCola does not record answers, timing, or any other practice details.

File check. verified means the file is exactly what LogiCola exported. altered means its signature does not match: it was edited after export, or damaged in transit, so ask the student to export it again. unsigned is an old file format whose levels cannot be verified.
